# Snow-plow service landing-page study

Historical static HTML/CSS frontend exercise with local photography, navigation, service sections, and a contact form. It has no application server, CMS, scheduling engine, or verified current business deployment.

Run `python -m http.server 8080 --bind 127.0.0.1` from this directory and open http://127.0.0.1:8080. Review the form action before reuse: the original form points at an external form provider. Local inspection does not verify that destination and does not require submitting messages.

`index.html` contains the document and form; `main.css` contains the layout; images are retained from the original study. Image rights and any historical business copy require owner confirmation before commercial reuse. Generated Windows download metadata has been removed, while source and the existing GPL-3.0 licence are preserved.
